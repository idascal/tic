La ce folosește un control ListBox?

Controlul ListBox este utilizat în aplicațiile cu interfață grafică (cum ar fi WinForms sau WPF) pentru a afișa o listă de elemente din care utilizatorul poate selecta unul sau mai multe obiecte.

În loc să folosești zeci de căsuțe separate pentru fiecare opțiune, un ListBox grupează totul într-un singur loc compact.

💡 Cele mai comune utilizări:

  • Selecția de opțiuni (Single Selection): Utilizatorul alege o singură variantă dintr-o listă predefinită (de exemplu: alegerea unei țări dintr-o listă, selectarea unui utilizator dintr-o bază de date sau alegerea unei dimensiuni de font).
  • Selecții multiple (Multiple Selection): Permite utilizatorului să selecteze mai multe elemente simultan folosind tastele Ctrl sau Shift (de exemplu: selectarea mai multor melodii pentru a crea un playlist sau alegerea categoriilor de interes dintr-un formular).
  • Afișarea și gestionarea de colecții (Liste dinamice): Este ideal pentru ecrane de tip „Coș de cumpărături” sau liste de sarcini (To-Do Lists), unde utilizatorul poate adăuga elemente noi în timp real sau le poate șterge pe cele existente.
  • Legarea la baze de date (Data Binding): Poate prelua automat informații din surse de date externe (tabele SQL, liste de obiecte din cod sau fișiere text) și le poate afișa ordonat sub formă de text (folosind proprietatea DisplayMember).

🔍 Comparație rapidă: Când folosești ListBox și când alegi altceva?

Control Când este cel mai bine să îl folosești?
ListBox Când ai o listă de elemente de dimensiune medie (5 - 50 elemente) și vrei ca toate opțiunile să fie vizibile pe ecran direct, sau când ai nevoie de selecție multiplă.
ComboBox Când spațiul pe ecran este limitat. Este o listă ascunsă care se deschide (drop-down) doar când dai click pe ea. Permite doar o singură selecție.
ListView Când lista ta este foarte complexă și ai nevoie de coloane, detalii suplimentare, pictograme mari sau organizare pe grupuri.

Exemplu Complet: Adăugare și Ștergere elemente în ListBox (C# WinForms)

Acesta este un exemplu de cod în C# WinForms care permite utilizatorului să adauge text dintr-o casetă (TextBox) într-un ListBox și să șteargă elementul selectat curent prin intermediul a două butoane.

1. Design-ul Formularului (Interfața Vizuală)

Pentru ca acest cod să funcționeze, trage din Toolbox pe formularul tău următoarele componente și redenumește-le (opțional, din proprietatea Name) astfel:

  • listBox1 (un control ListBox)
  • txtElementNou (un control TextBox pentru introducerea textului)
  • btnAdauga (un buton pentru adăugare)
  • btnSterge (un buton pentru ștergere)

2. Codul din spatele Formularului (Form1.cs)

Dă dublu-click pe butoane în interfața grafică pentru a le genera evenimentele de Click și adaugă următorul cod:

using System;
using System.Windows.Forms;

namespace ExempluListBox
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
        }

        // Evenimentul pentru butonul de adăugare
        private void btnAdauga_Click(object sender, EventArgs e)
        {
            // Verificăm dacă utilizatorul a introdus text (eliminând spațiile goale)
            if (!string.IsNullOrWhiteSpace(txtElementNou.Text))
            {
                // Adăugăm textul în ListBox
                listBox1.Items.Add(txtElementNou.Text);

                // Curățăm căsuța de text pentru o nouă introducere
                txtElementNou.Clear();
                txtElementNou.Focus(); // Punem cursorul înapoi în căsuță
            }
            else
            {
                MessageBox.Show("Te rog să introduci un text mai întâi!", "Atenție", MessageBoxButtons.OK, MessageBoxIcon.Warning);
            }
        }

        // Evenimentul pentru butonul de ștergere
        private void btnSterge_Click(object sender, EventArgs e)
        {
            // Verificăm dacă este selectat vreun element în ListBox
            // Dacă SelectedIndex este -1, înseamnă că nu s-a selectat nimic
            if (listBox1.SelectedIndex != -1)
            {
                // Ștergem elementul de la poziția (indexul) selectată
                listBox1.Items.RemoveAt(listBox1.SelectedIndex);
            }
            else
            {
                MessageBox.Show("Te rog să selectezi un element din listă pentru a-l șterge!", "Atenție", MessageBoxButtons.OK, MessageBoxIcon.Information);
            }
        }
    }
}

3. Cum funcționează

  • Adăugarea: Scrii un cuvânt în căsuța de text și apeși butonul „Adaugă”. Codul verifică să nu fie gol, îl pune în listă și golește căsuța ca să poți scrie următorul element.
  • Ștergerea: Dai click pe oricare element din listă (devine albastru) și apeși butonul „Șterge”. Codul verifică dacă ai selectat ceva corect și îl elimină instant prin metoda RemoveAt().

Ghid Avansat: Încărcarea și Gestiunea Datelor în ListBox (C# WinForms)

Acest document centralizează două metode esențiale de lucru cu ListBox: utilizarea unui Array static pentru colecții fixe și utilizarea unei Liste dinamice (BindingList) prin Data Binding pentru sincronizare automată.

Metoda 1: Preluarea elementelor dintr-un Array static

Această metodă este ideală atunci când ai o listă fixă de opțiuni care nu se schimbă pe parcursul rulării aplicației. Încărcarea se face la pornirea formularului (evenimentul Load).

Codul sursă C# (Form1.cs)

using System;
using System.Windows.Forms;

namespace ExempluListBoxArray
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
        }

        // Se execută automat când se deschide fereastra aplicației
        private void Form1_Load(object sender, EventArgs e)
        {
            // 1. Declarăm și inițializăm un array cu elemente fixe
            string[] masini = { "Dacia Logan", "Volkswagen Golf", "BMW Seria 3", "Audi A4", "Ford Focus" };

            // 2. Curățăm ListBox-ul pentru a evita dublarea elementelor
            listBox1.Items.Clear();

            // 3. Adăugăm rapid tot vectorul în ListBox
            listBox1.Items.AddRange(masini);
        }

        // Opțional: Afișează ce element a fost selectat
        private void listBox1_SelectedIndexChanged(object sender, EventArgs e)
        {
            if (listBox1.SelectedIndex != -1)
            {
                string masinaSelectata = listBox1.SelectedItem.ToString();
                MessageBox.Show($"Ai selectat mașina: {masinaSelectata}", "Selecție");
            }
        }
    }
}

Alternativă cu DataSource (Read-Only)

Dacă asignezi array-ul prin sursa de date: listBox1.DataSource = orase;, structura din interfață devine blocată. Nu vei mai putea folosi metodele .Add() sau .Remove() direct pe ListBox din cauza limitărilor de dimensiune fixă ale array-ului.

Metoda 2: Gestiunea dinamică folosind o Listă (BindingList)

Cea mai bună practică în WinForms implică separarea datelor de design. Utilizând BindingList<T>, orice modificare adusă listei din cod se va reflecta automat pe ecran, eliminând nevoia de a scrie manual cod de reîmprospătare.

Codul sursă C# (Form1.cs)

using System;
using System.ComponentModel; // Necesar pentru BindingList
using System.Windows.Forms;

namespace ExempluListBoxLista
{
    public partial class Form1 : Form
    {
        // Declarăm lista dinamică la nivelul clasei
        private BindingList<string> listaCumparaturi;

        public Form1()
        {
            InitializeComponent();
        }

        private void Form1_Load(object sender, EventArgs e)
        {
            // 1. Inițializăm lista cu câteva elemente standard
            listaCumparaturi = new BindingList<string> { "Lapte", "Pâine", "Ouă" };

            // 2. Legăm lista direct la ListBox
            listBox1.DataSource = listaCumparaturi;
        }

        // Evenimentul butonului de adăugare
        private void btnAdauga_Click(object sender, EventArgs e)
        {
            string elementNou = txtElement.Text.Trim();

            if (!string.IsNullOrWhiteSpace(elementNou))
            {
                // Adăugăm în LISTĂ, nu în ListBox! Interfața se actualizează singură.
                listaCumparaturi.Add(elementNou);
                txtElement.Clear();
                txtElement.Focus();
            }
        }

        // Evenimentul butonului de ștergere
        private void btnSterge_Click(object sender, EventArgs e)
        {
            if (listBox1.SelectedIndex != -1)
            {
                string elementDeSters = listBox1.SelectedItem.ToString();
                
                // Ștergem direct din LISTĂ
                listaCumparaturi.Remove(elementDeSters);
            }
            else
            {
                MessageBox.Show("Selectează un produs din listă pentru a-l șterge!");
            }
        }
    }
}

De ce este superioară metoda cu Listă (Data Binding)?

  1. Separarea conceptelor: Datele stau stocate în siguranță în variabila din C#, în timp ce controlul vizual doar le desenează.
  2. Sincronizare nativă: Când vrei să trimiți datele către salvare (bază de date/fișier JSON), nu mai extragi rândurile din ListBox, ci lucrezi direct cu listaCumparaturi.
  3. Scalabilitate rapidă: Dacă decizi ulterior să transformi lista de string-uri simple într-o listă de obiecte complexe (ex: o clasă Produs cu proprietăți precum Nume și Preț), logica adăugării și ștergerii rămâne intactă.
