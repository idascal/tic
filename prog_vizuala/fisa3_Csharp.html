Citire din fisier CSV sau TXT si memorare in vector(array)

IExemplu complet de aplicație Windows Forms (C#) care citește date dintr-un fișier text (de exemplu, un fișier de tip CSV sau TXT delimitat prin virgulă/virgulă și punct) și calculeaza suma numerelor citite.

  1. Citește un șir de numere întregi dintr-un fișier .txt.
  2. Salvează numerele într-un int[].
  3. Calculează suma elementelor din array.
  4. Afișează numerele și suma în interfață.

Pasul 1: Pregătirea Interfeței Grafice (Designer)

  1. Deschide Visual Studio și creează un proiect nou de tip Windows Forms App (.NET Framework sau .NET) în C#.
  2. Pe formularul principal (Form1), adaugă următoarele controale din Toolbox:
    • Button (Name: btnIncarca, Text: "Încarcă fișier")
    • TextBox → Name: txtNumere
    • Label → Name: lblSuma, Text: Suma:
    • OpenFileDialog (Name: openFileDialog1)

Pasul 2: Codul C# (Form1.cs)

Dă dublu-click pe butonul btnIncarca pentru a genera evenimentul Click, apoi înlocuiește codul din Form1.cs cu următoarea implementare:


using System;
using System.IO;
using System.Linq;
using System.Windows.Forms;

namespace AplicatieNumere
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
        }

        private void btnCiteste_Click(object sender, EventArgs e)
        {
            // Creăm OpenFileDialog
            OpenFileDialog openFileDialog = new OpenFileDialog();

            // Filtrăm pentru fișiere .txt
            openFileDialog.Filter = "Fișiere text (*.txt)|*.txt|Toate fișierele (*.*)|*.*";

            // Titlul ferestrei
            openFileDialog.Title = "Selectează fișierul cu numere";

            // Deschidem fereastra
            if (openFileDialog.ShowDialog() == DialogResult.OK)
            {
                try
                {
                    // Citim conținutul fișierului
                    string text = File.ReadAllText(openFileDialog.FileName);

                    // Transformăm numerele într-un array
                    int[] numere = text
                        .Split(new char[] { ' ', '\r', '\n', '\t' },StringSplitOptions.RemoveEmptyEntries)
                        .Select(int.Parse)
                        .ToArray();

                    // Calculăm suma
                    int suma = 0;

                    foreach (int numar in numere)
                    {
                        suma += numar;
                    }

                    // Afișăm numerele
                    txtNumere.Text = string.Join(" ", numere);

                    // Afișăm suma
                    lblSuma.Text = "Suma = " + suma;
                }
                catch (FormatException)
                {
                    MessageBox.Show(
                        "Fișierul conține valori care nu sunt numere întregi.",
                        "Eroare",
                        MessageBoxButtons.OK,
                        MessageBoxIcon.Error);
                }
                catch (Exception ex)
                {
                    MessageBox.Show(
                        "A apărut o eroare: " + ex.Message,
                        "Eroare",
                        MessageBoxButtons.OK,
                        MessageBoxIcon.Error);
                }
            }
        }
    }
}
