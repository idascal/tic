Citire din fisier CSV si afisare in DataGridView

IExemplu complet de aplicație Windows Forms (C#) care citește date dintr-un fișier text (de exemplu, un fișier de tip CSV sau delimitat prin virgulă/virgulă și punct) și le afișează într-un control DataGridView.

Pasul 1: Pregătirea Interfeței Grafice (Designer)

  1. Deschide Visual Studio și creează un proiect nou de tip Windows Forms App (.NET Framework sau .NET) în C#.
  2. Pe formularul principal (Form1), adaugă următoarele controale din Toolbox:
    • Button (Name: btnIncarca, Text: "Încarcă fișier")
    • Button (Name: btnSalveaza, Text: "Salvează date in fișier")
    • DataGridView (Name: dataGridView1)
    • OpenFileDialog (Name: openFileDialog1)
    • SaveFileDialog (Name: saveFileDialog1)

Pasul 2: Codul C# (Form1.cs)

Dă dublu-click pe butonul btnIncarca pentru a genera evenimentul Click, apoi înlocuiește codul din Form1.cs cu următoarea implementare:


using System;           
using System.Data;
using System.IO;
using System.Windows.Forms;

namespace CitireFisierDataGridView
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
        }

        private void btnIncarca_Click(object sender, EventArgs e)
        {
            // Setăm filtrele pentru OpenFileDialog
            openFileDialog1.Filter = "Fișiere Text/CSV (*.txt;*.csv)|*.txt;*.csv|Toate fișierele (*.*)|*.*";
            openFileDialog1.Title = "Selectează fișierul de date";

            if (openFileDialog1.ShowDialog() == DialogResult.OK)
            {
                string caleFisier = openFileDialog1.FileName;

                try
                {
                    DataTable dataTable = CitesteDateDinFisier(caleFisier, ','); // Schimbă separatorul (ex: ';' sau '\t') dacă este nevoie
                    dataGridView1.DataSource = dataTable;
                    
                    MessageBox.Show("Datele au fost încărcate cu succes!", "Succes", MessageBoxButtons.OK, MessageBoxIcon.Information);
                }
                catch (Exception ex)
                {
                    MessageBox.Show($"Eroare la citirea fișierului: {ex.Message}", "Eroare", MessageBoxButtons.OK, MessageBoxIcon.Error);
                }
            }
        }

        private DataTable CitesteDateDinFisier(string caleFisier, char separator)
        {
            DataTable dt = new DataTable();

            using (StreamReader sr = new StreamReader(caleFisier))
            {
                string linie;
                bool estePrimaLinie = true;

                while ((linie = sr.ReadLine()) != null)
                {
                    // Ignorăm liniile goale
                    if (string.IsNullOrWhiteSpace(linie)) 
                        continue;

                    string[] valori = linie.Split(separator);

                    if (estePrimaLinie)
                    {
                        // Prima linie din fișier este considerată Antetul tabelului (numele coloanelor)
                        foreach (string valoare in valori)
                        {
                            dt.Columns.Add(valoare.Trim());
                        }
                        estePrimaLinie = false;
                    }
                    else
                    {
                        // Restul liniilor reprezintă datele
                        DataRow row = dt.NewRow();

                        for (int i = 0; i < valori.Length && i < dt.Columns.Count; i++)
                        {
                            row[i] = valori[i].Trim();
                        }

                        dt.Rows.Add(row);
                    }
                }
            }

            return dt;
        }
    }
}

Pasul 3: Model de fișier text de test

Creează un fișier text date.txt sau date.csv pe calculatorul tău cu următorul conținut:

Nume,Prenume,Varsta,Oras
Popescu,Ion,30,Bucuresti
Ionescu,Maria,25,Cluj-Napoca
Radu,Andrei,40,Timisoara

Explicație rapidă

  • DataTable: Creează o structură tabelară în memorie. Prima linie din fișierul text devine numele coloanelor, iar liniile următoare devin rândurile de date (DataRow).
  • StreamReader: Citește fișierul linie cu linie pentru o gestionare eficientă a memoriei.
  • linie.Split(separator): Împarte linia citită după caracterul specificat (implicit virgulă ,, dar poate fi modificat în ; sau \t pentru tab-uri).
  • dataGridView1.DataSource: Leagă DataTable-ul direct de interfață, completând automat celulele.

Pasul 3: Salvarea datelor din DataGridView in fișier"


private void btnSalveaza_Click(object sender, EventArgs e)
{
    using (SaveFileDialog dialog = new SaveFileDialog())
    {
        dialog.Filter = "Fișiere text (*.txt)|*.txt";
        dialog.Title = "Salvează datele";

        if (dialog.ShowDialog() == DialogResult.OK)
        {
            using (StreamWriter sw = new StreamWriter(dialog.FileName, false, Encoding.UTF8))
            {
                // Coloane
                for (int i = 0; i < dataGridView1.Columns.Count; i++)
                {
                    sw.Write(dataGridView1.Columns[i].HeaderText);

                    if (i < dataGridView1.Columns.Count - 1)
                        sw.Write(";");
                }

                sw.WriteLine();

                // Rânduri
                foreach (DataGridViewRow row in dataGridView1.Rows)
                {
                    if (row.IsNewRow)
                        continue;

                    for (int i = 0; i < dataGridView1.Columns.Count; i++)
                    {
                        sw.Write(row.Cells[i].Value?.ToString() ?? "");

                        if (i < dataGridView1.Columns.Count - 1)
                            sw.Write(";");
                    }

                    sw.WriteLine();
                }
            }

            MessageBox.Show("Datele au fost salvate!");
        }
    }
}
